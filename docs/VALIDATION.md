## 权限和运行边界

继承原型的 `danger-full-access` 执行预设和 GitHub CLI 账号工作范式。允许名单只控制 QQ 来源；部署在当前操作系统账号下的 Worker 具有该执行预设对应的工作能力。请使用适合个人助手任务的工作账号和仓库。

每个 Bot 独立持久化数据库、主控和任务 Session、Outbox、媒体库及执行环境。共享模型账号、DSH 宿主和底层操作系统账号。异步结果会进入持久化 relay，实际主动消息仍受 QQ 开放平台额度、会话有效期和应用权限约束；发送失败保留在 Outbox/健康状态中供排查与重试。

## 真实 QQ 验收

两个 Bot 经过新主控和 Outbox 成功回复。一个 Bot 的后台联网搜索完成后，经持久化 relay 唤醒主控，主动回复搜索结果，期间无新增人类消息。另一个 Bot 实际调用 read_image 查看已审核图片，再调用 sticker_send 成功发送；QQ 界面显示图片。

启动项继续使用 macOS LaunchAgent 和 caffeinate，提供登录后自动后台启动及锁屏在线。
