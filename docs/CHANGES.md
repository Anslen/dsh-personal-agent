# 上游改动边界

## Super-agent

- managementPath：每个 Bot 单独的管理接口前缀。
- extraTools：主控与执行器可挂载表情工具。
- packaged paths：单仓库构建后仍定位到原始 prompts 和 skills。
- 其余 Engine、事务、Effects 和任务生命周期保留上游实现。

## QQ

- externalDriver：消息经过原渠道过滤后交给外部驱动，失败不退入原有模型链。
- 注册实例发送器以供 Source 出站；卸载时清理。
- 源码仍保留原有能力，外部模式下会话编排归 Super-agent。

## 表情

- 配置、角色集合、路径、CLI 命令从部署环境读取。
- 原会话的任务ID与搜索结果绑定；完成事件通过原型relay而非静默notify投递。
- 公共代码没有部署者的Bot凭据、AppID或允许名单。

- QQ 聚合与最终入站入口统一切换到外部主控，补充不创建旧 Session 的回归。
- 多 Bot 浏览器面板复用原型工单界面；API 基路径按实例传递。
- 原型 Feishu 消费器修复 stdout/stderr 到达顺序导致解析错误被 ready 覆盖的问题。
- 工具执行环境使用异步上下文路由，共享宿主内不改进程级环境。

- 审核v4：多参考图与正向身份描述；脚本完成OCR、标签和对照图，模型一次简短复核决定采纳，参考图内容纳入审核指纹。
- 已保存素材支持直接重新审核，历史判断写入review_history保留。
- 配置迁移：将单张referenceImage改为2至6张referenceImages，并补充identityDescription。

- 发送时由后台取得当前会话的图片授权，模型只选择id，避免任务编号与发送凭据混淆。
- 移除表情风格的强制偏好和打分门槛。

- 统一sticker_view图片附件入口，任务执行器可直接看图；聊天工具说明修改不会触发图库复核。

- 加强主动表情检索提示：根据话题与情绪主动检索，图库不贴切时立即异步补充。
- 主控可直接基于已授权人类消息发起搜索，完成事件回到原会话，无需建立执行任务。

- 搜索未获新可用素材时持久化继续，自动换词和来源并退避重试，支持查询和取消。
- 重复图片不消耗新候选复核额度，GitHub来源使用已登录CLI，完成后可按素材id直接取图。

- 接入qq_history：访问控制后、唤醒判断前归档，按Bot和会话隔离，支持关键词和稳定游标分页；保留7天可读窗口、每会话最多2000条。
- 群聊仅明确@机器人时进入主控；普通消息归档后立即结束处理，不运行入站扩展、聚合或模型调用。
- qq_history支持起止时间、发送人ID或昵称与所有人筛选；默认上下文保持不变，提示模型在需要额外信息时按需查询。
- 引用关系与可用原文、附件随历史和入站消息一起传给模型；同会话持久化索引支持重启后解析，引用图片可直接查看。
- 新入站只附历史条数与更新时间，正文仍按需查询；明确查询历史或总结当前消息时要求本轮重新检索，工具返回可核对的快照与分页状态。
- 历史结果只作为查询当时的快照，后续模型调用始终按可能有新消息处理，需要背景时主动重查；条数和更新时间相同也不延长旧结果的时效。

- 修复qq_history未填写时间筛选时返回undefined导致宿主拒绝工具输出；返回前规范化可选引用字段，符合无损JSON契约。
- 增加共享表情库、异步会话图片收藏和看图后打标；后台完成采纳前不可检索发送，收藏默认静默完成，可选择完成回调。
- 入站即时确认持久化去重，不等待模型就绪或任务完成；移除外部主控的旧聚合等待，Agent自主决定任务执行方式。
- 提示文本统一收纳到prompts目录：规则、后台任务、工具说明、QQ扩展、框架模板与技能均有统一索引，旧路径通过符号链接兼容，正文与参数拼接分离。

- 移除渠道固定收件确认及相关配置，首次回复由模型自然生成，继续支持自主后台执行和完成交付。
